## 🐛 Troubleshooting

### "No account found with this email"
**Solution**:
- **Force close and reopen app** (triggers account creation on launch)
- **Wait 10 seconds** after first app launch for all accounts to create
- Check debug logs: should see "✅ Test account verified: [email]"
- If persists: uninstall app, reinstall APK, wait 10 seconds

### "Invalid password"
**Solution**:
- **Passwords are case-sensitive!**
- Copy exact password from this guide
- Check **Caps Lock is OFF**
- Common errors:
  - ✅ `FlowAiDemo2025!` (correct)
  - ❌ `flowAiDemo2025!` (wrong - lowercase f)
  - ❌ `FlowAiDemo2025` (wrong - missing !)
  - ❌ `FLOWAIDEMO2025!` (wrong - all caps)

### Account not persisting after logout
**Solution**:
- ✅ **Fixed in Build 15** - all accounts now persist reliably
- Accounts stored in local SQLite database
- Data survives app restarts and updates
- Simply login again with same credentials

### Need to test onboarding flow?
**Solution**:
- Use **qa@flowai.app** account
- This account has **NO pre-loaded data**
- Onboarding **NOT completed**
- Perfect for testing first-time user experience

### Want different data profiles?
**Quick Reference**:
- **6 months data** → demo@flowai.app
- **3 months data** → tester1@flowai.app
- **1 month data** → tester2@flowai.app
- **No data (clean)** → qa@flowai.app
- **12 months data** → dev@flowai.app

### App crashes on login
**Solution**:
1. **Uninstall app completely** (clear all data)
2. **Reinstall fresh APK**
3. **Wait 10 seconds** after first launch
4. **Check logs** for "✅ Test accounts created" message
5. **Try demo@flowai.app first** (most tested account)

### Debug logs not showing
**Solution**:
- Connect device to computer
- Open Android Studio / Xcode
- View debug console
- Launch app and watch for account creation logs
